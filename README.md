# ML Starter Guide

A curated path from Python fundamentals to your first machine learning models.
Work through the phases in order — each one builds on the last.

---

## Phase 1 — Python Foundations

Get comfortable writing real Python before touching any ML library.

- **[Practical Python Programming](https://dabeaz-course.github.io/practical-python/Notes/Contents.html)** — David Beazley
  A full course on idiomatic Python: data structures, functions, classes, generators, modules, testing.
  Do the exercises; they're the point.

---

## Phase 2 — The Data Stack

The two libraries every ML workflow sits on top of.

- **[NumPy Tutorial](https://www.kaggle.com/code/landlord/numpy-tutorial)** — arrays, broadcasting, vectorized math
- **[Pandas](https://www.kaggle.com/learn/pandas)** — Kaggle Learn: loading, indexing, grouping, joining, cleaning data

---

## Phase 3 — The Math Behind It

Build intuition first, formalism second. These are visual courses — watch actively, pause, sketch.

- **[Essence of Linear Algebra](https://www.youtube.com/watch?v=fNk_zzaMoSs&list=PLZHQObOWTQDPD3MizzM2xVFitgF8hE_ab)** — 3Blue1Brown
  Vectors, matrices as transformations, determinants, eigenvectors. The backbone of every model.

- **[The Essence of Calculus](https://www.youtube.com/watch?v=WUvTyaaNkzM&t=12s)** — 3Blue1Brown
  Derivatives, chain rule, integrals. This is what gradient descent actually is.

- **[Probability Bootcamp](https://www.youtube.com/watch?v=sQqniayndb4&list=PLMrJAkhIeNNR3sNYvfgiKgcStwuPSts9V)**
  Distributions, expectation, Bayes. Underpins everything from loss functions to model evaluation.

---

## Phase 4 — Machine Learning

- **[Intro to Machine Learning](https://www.kaggle.com/learn/intro-to-machine-learning)** — Kaggle Learn
  Decision trees, random forests, train/validation splits, underfitting vs. overfitting, model validation.

---

## How to Work Through This

1. **Code along, don't just read.** Type every example out yourself.
2. **Phases 2 and 3 can run in parallel** — do a Kaggle lesson in the morning, a math video in the evening.
3. **Finish Phase 1 before starting Phase 2.** Fighting the language while learning pandas is twice the work.
4. **Ship something small after Phase 4** — a Kaggle competition entry, or a model on a dataset you actually care about.

---

## Suggested Pace

| Phase | Focus | Rough time |
|-------|-------|-----------|
| 1 | Python foundations | 2–3 weeks |
| 2 | NumPy + Pandas | 1–2 weeks |
| 3 | Linear algebra, calculus, probability | 3–4 weeks |
| 4 | Intro to ML | 1–2 weeks |

Adjust to your own schedule — consistency beats speed.
